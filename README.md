# rajarshi-bose.github.io

Portfolio website that connects to the rest of my projects.

**Live site: [jarsh.us](https://jarsh.us)**

## About

Personal portfolio for Rajarshi "Jarsh" Bose, a Mechanical Engineering student at Texas A&M University (Class of 2027). It collects my engineering work in propulsion, fluid systems, and simulation, along with the games and tools I build on the side.

## What's on the site

- **Projects:** a grid of everything I've worked on. Hover a tile to see its type and status, and click it for the full write-up.
- **About:** education, research, and where I'm headed.
- **Art Collection:** work made outside the lab.

Featured projects include [Ten Year Tape](https://github.com/rajarshi-bose/ten-year-tape), [Isle of Man](https://github.com/rajarshi-bose/isle-of-man), [Dither Press](https://github.com/rajarshi-bose/dither-press), and my research and Formula SAE work. Each app lives in its own repo. Because this is my main GitHub Pages site on `jarsh.us`, every other repo with Pages turned on appears under the same domain: [jarsh.us/ten-year-tape](https://jarsh.us/ten-year-tape/), [jarsh.us/dither-press](https://jarsh.us/dither-press/) and [jarsh.us/isle-of-man](https://jarsh.us/isle-of-man/).

## How it's built

The whole site is a single `index.html` file with no build step: plain HTML, CSS, and JavaScript. Fonts are Geist Pixel (headings), Fragment Mono (body text), and Sono (labels). It's hosted on GitHub Pages with the custom domain `jarsh.us`.

## Versions

The current version and a change log are in the bottom-right corner of the site. Each update raises the version by 0.01.
